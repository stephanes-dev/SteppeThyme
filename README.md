# SteppeThyme

SteppeThyme is a data-driven geo-spatial analysis platform that leverages real-time data processing for map engine optimization.

SteppeThyme is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/SteppeThyme.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
